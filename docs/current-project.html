CURRENT PROJECT · TELEMETRY PIPELINE

车间遥测数据流

CSV 上传、异步任务处理、TimescaleDB 落库与前端任务管理

Worker 周期 5 秒 · 单文件上限 1,000,000 行
1

下位机上传

仅接受 .csv 文件，创建文件对象并生成遥测任务。

POST /api/workshop/telemetry/upload
›
2

文件与任务持久化

文件写入 Blob:Path，任务状态初始化为 Pending。

FileObject + WorkshopTelemetryTask
›
3

Worker 认领

每 5 秒扫描待处理任务，每批最多认领 5 个。

Pending → Processing
›
4

CSV 校验与批量导入

校验设备编码、指标、数值和时间，无效行跳过。

DeviceCode, MetricType, Value, Timestamp, TestedDeviceCode, TestedDeviceName
›
5

TimescaleDB 落库

通过 PostgreSQL COPY 写入临时表，再执行冲突更新。

AppWorkshopDeviceTelemetries · DeviceId + Timestamp + MetricType
›
6

任务结果与界面

记录成功/失败、记录数、错误信息；支持重试和预览。

GET /api/workshop/telemetry/statistics · retry · delete

卡死恢复

Processing 超过 10 分钟的任务会恢复为 Pending，并增加重试次数。

失败退避

失败后按 2^RetryCount 分钟延迟，最长 60 分钟；仅失败任务允许手动重试。

过期清理

每小时清理过期任务、文件对象和物理文件；审计/安全日志保留 365 天。

指标类型：Pressure / Temp / Flow / Vibration
